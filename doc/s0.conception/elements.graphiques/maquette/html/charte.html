05

Lien avec shadcn/ui

Chaque pattern visuel de la maquette se mappe à une primitive shadcn/ui (composants Tailwind + Radix UI). La maquette HTML est volontairement structurée pour faciliter cette transposition React.

Élément LaPince Composant shadcn/ui Primitive Radix Où dans l'app
Boutons (accent / primaire / outline) <Button variant /> — Partout (CTA, footers de modale)
Champ texte / nombre / email <Input /> — Formulaires, recherche
Zone de texte <Textarea /> — Description du projet
Étiquette de champ <Label /> @radix-ui/react-label Formulaires
Cartes (KPI, budget, balance) <Card /> — Vue d'ensemble, listes
Modales (Projet, Opération, Budgets, Inviter…) <Dialog /> @radix-ui/react-dialog Toutes les modales
Onglets (Vue d'ensemble / Détails / Opérations) <Tabs /> @radix-ui/react-tabs Détail projet
Avatars + stack participants <Avatar /> @radix-ui/react-avatar En-tête projet, bénéficiaires
Badges (rôles, statuts de solde) <Badge /> — Percepteur / Donateur / Invité
Sélecteurs (catégorie, payé par, rôle) <Select /> @radix-ui/react-select Opérations, budgets
Toggle Archiver <Switch /> @radix-ui/react-switch En-tête projet
Slider seuil d'alerte <Slider /> @radix-ui/react-slider Alerte budget
Cases à cocher (alerte, participants) <Checkbox /> @radix-ui/react-checkbox Modale opération, alerte
Filtres segmentés <ToggleGroup /> @radix-ui/react-toggle-group Projets, opérations
Tooltips (icônes catégories du budget) <Tooltip /> @radix-ui/react-tooltip Barre de budget
Tableaux (projets, opérations) <Table /> — Listes

Installation type : npx shadcn@latest add button input dialog tabs select switch slider checkbox badge avatar tooltip table
