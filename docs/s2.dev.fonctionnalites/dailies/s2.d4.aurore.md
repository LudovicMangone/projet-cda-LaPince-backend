## 🧠 Problème majeur rencontré

Gros blocage sur la synchronisation du state local des participants côté front.
Les modifications n’étaient pas persistées et disparaissaient après sauvegarde ou navigation.

Après analyse, le problème venait d’un ensemble de causes combinées côté front et back :

* mauvaise synchronisation entre state local et state global (context React)
* resynchronisation automatique du form écrasant les données en cours d’édition
* incohérences de typage sur les participants (undefined dans le mapping)
* problème de transaction côté backend empêchant le retour correct des données créées

➡️ Résultat : comportement instable du formulaire nécessitant un refresh complet pour voir les changements.
