### Analyse métier et technique

Lors de l'implémentation des routes de modification et suppression de projet :

* Constat d'un écart entre les maquettes et le modèle de données.
* Les maquettes permettent d'associer un tag ou une catégorie à un projet.
* Cette notion n'existe actuellement pas dans le MCD, le MLD, le MPD ni dans le schéma Prisma.
* Les catégories sont aujourd'hui uniquement prévues pour les opérations.

Décision prise :

* Conserver le bouton présent dans l'interface mais le passer en commentaire pour masquer son affichage.
* Reporter son implémentation à une évolution ultérieure nécessitant une adaptation du modèle de données.
