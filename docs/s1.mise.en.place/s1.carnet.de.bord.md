# 🗓️ Carnet de bord collectif — Sprint 1 : Mise en place technique

---

## 26/05/26 — Sprint 1 / Day 1

Le Sprint 1 débute avec la mise en place technique du projet et la création des bases de travail communes pour le front-end et le back-end.

L’équipe a travaillé collectivement toute la journée sur l’initialisation des repositories et la configuration de l’environnement de développement.

### Mise en place du front-end

Installation et configuration des principaux outils de la stack :

* Biome pour le linting et le formatage
* formatage automatique VSCode
* Husky pour les hooks Git
* GitHub Actions pour le CI/CD
* Vitest pour les tests unitaires

Des tests collaboratifs ont été réalisés afin de valider :

* le workflow Git,
* les Pull Requests,
* le fonctionnement des pipelines CI.

### Mise en place du back-end

En parallèle, les premières bases du back-end ont été initialisées :

* démarrage d’Express,
* structuration du projet,
* début de mise en place du socle technique backend.

### Infrastructure

Début de configuration :

* Dockerfile,
* docker-compose,
* environnement de développement conteneurisé.

### Décisions techniques

L’équipe a identifié une vulnérabilité sur Prisma 7 et a décidé temporairement de passer sur Prisma 6 afin de stabiliser l’environnement de travail.

### Synthèse

Cette première journée du sprint a permis de :

* stabiliser l’environnement de développement,
* valider les workflows Git et CI/CD,
* poser les bases techniques du projet côté front et back.

---

## 27/05/26 — Sprint 1 / Day 2

La journée a été consacrée à la consolidation du socle backend, à la sécurité de l’API et à la poursuite de l’organisation du projet.

### Point collectif du matin

L’équipe a résolu un problème Docker lié à PostgreSQL 18 :
le répertoire de données ayant changé entre les versions, l’ancienne configuration provoquait un bug de montage des volumes.

Les GitHub Actions ont également été corrigées et rendues fonctionnelles.

### Répartition du socle technique

L’équipe a réparti les principaux sujets techniques :

* configuration Prisma et base de données,
* sécurité backend et middlewares,
* organisation projet,
* premiers composants front et landing page.

### Sécurité backend

Le socle de sécurité de l’API a commencé à être mis en place avec :

* gestion centralisée des erreurs,
* middleware 404,
* validation des variables d’environnement,
* configuration de `cors`,
* sécurisation HTTP via `helmet`,
* protection XSS,
* limitation du nombre de requêtes.

### Documentation

Début de rédaction de :

* la documentation technique,
* la documentation RGPD,
* les README du projet.

### Ajustement Prisma

Après analyse de l’équipe, retour sur Prisma 7 :
la vulnérabilité identifiée sur Prisma 6 concernait une dépendance non utilisée dans le projet.

### Synthèse

Cette journée a permis :

* de renforcer la sécurité backend,
* de stabiliser l’environnement Docker,
* de poursuivre l’organisation du projet,
* et de structurer les premières bases documentaires.

---

## 28/05/26 — Sprint 1 / Day 3

La journée a été centrée sur la structuration des couches applicatives et la poursuite de la documentation du projet.

### Point collectif du matin

Le front-end dispose désormais d’une première base fonctionnelle avec plusieurs pages mises en place.

L’équipe a également échangé sur l’architecture backend et la séparation des responsabilités :

* contrôleurs pour la logique HTTP,
* services pour la logique métier,
* accès aux données isolé dans les couches dédiées.

### Point avec l’équipe encadrante

Retour positif sur l’avancement global du projet.

Points de vigilance rappelés :

* responsive design,
* approche mobile first,
* accessibilité,
* suivi quotidien collectif et individuel.

### Documentation et organisation

Travail poursuivi sur :

* les README,
* l’architecture projet,
* la documentation RGPD,
* les carnets de bord du sprint.

### Synthèse

Le Sprint 1 avance de manière stable avec :

* un environnement technique désormais fonctionnel,
* une architecture applicative qui se clarifie,
* et une documentation projet de plus en plus structurée.
